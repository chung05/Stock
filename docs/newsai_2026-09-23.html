台股盤前焦點分析報告

發布日期: 2026年09月23日 (開盤前)

📈國際大盤焦點

  • 美股表現：隔夜美股科技股強勢反彈，那斯達克指數上漲0.45%，費城半導體指數更飆漲2.06%，顯著優於道瓊工業指數的-0.36%跌幅。這顯示市場資金再度湧入AI與半導體相關族群，為台股電子權值股帶來正面激勵。
  • 台積電ADR動態：台積電ADR（TSM）收盤大漲1.54%，強勢表現預示台積電今日開盤有機會補漲，對台股大盤具有穩定作用。
  • 台指期夜盤收盤解析：台指期近月夜盤收盤上漲0.56%，反應美股科技股的強勁表現，顯示台股今日開盤氛圍偏多。
  • 重要經濟數據與國際新聞：
    • 台灣外銷訂單創新高：8月外銷訂單金額首度突破1,000億美元大關，達1,029.6億美元，年增71.4%，連續19個月正成長，主要受惠於AI、高效能運算及雲端服務需求極速擴張，特別是電子和資訊通信產品年增率分別高達83.9%和100.5%，美國為最大訂單來源。這數據為台股基本面提供強勁支撐。
    • 美國升息疑慮再起：聖路易聯準銀行總裁慕薩勒表示，為抑制通膨可能需進一步升息，此鷹派言論可能對利率敏感型產業造成潛在壓力，但目前AI題材熱度仍高，市場消化情況待觀察。
    • 川習會與地緣政治：美國總統川普與中國國家主席習近平本週將舉行峰會，台灣議題（對台軍售）、貿易休兵（11月10日到期）及AI競爭是焦點。中美雙方釋出延續貿易休兵的訊號，有望為市場帶來短期穩定，但長期地緣政治風險仍存。此外，美國五角大廈將近200家中國企業列入黑名單（包括阿里巴巴、百度等AI巨頭），可能加劇中美科技競爭，但也可能為非中國供應鏈帶來轉單效益。
    • 南韓對美投資：南韓政府計劃對美國德州燃氣發電廠、大型核電廠（收購西屋電氣股份）及阿拉斯加液化天然氣開發投資3,500億美元，顯示全球資本在能源轉型與基礎建設的流向。
    • 台股第四季展望：統計近五年全球主要股市第四季平均表現，台股加權指數平均漲幅近7.67%居冠全球，顯示第四季具傳統旺季效應與資金輪動機會。

🚀今日重大個股利多

  • 聯發科 (2454)：推出全新Dimensity CX C10 Max旗艦SoC，採用台積電3奈米製程，鎖定Googlebook高階、超便攜筆電市場，AI算力最高達55 TOPS。法人預期聯發科獲利將因Google TPU ASIC訂單而倍增，外資美林估明年EPS達137元，2028年上看327元，股價具挑戰萬元潛力。
  • 創意 (3443)：8月營收達58.4億元，年增111.02%，累計前8月年增103.84%，創歷史新高。HBM4E PHY與Controller IP已完成設計定案，獲客戶AI ASIC採用，導入台積電2奈米強化版(N2P)製程與CoWoS-L封裝技術。法人預估今年EPS 58.23元，2027年達139.12元，成長動能強勁。
  • 信驊 (5274)：股價衝上21,800元，寫下台股歷史新高，成為首支突破2萬元的個股。8月營收連續10個月創新高，公司表示2027年訂單量已超越今年全年營收規模，並預期明年營運價量齊揚，產品ASP有機會達20美元。為確保產能，已與日月光投控（3711）簽訂2年採購合約。
  • 友達 (2409) / 群創 (3481)：外資連兩日狂掃友達逾48萬張，激勵股價連續漲停。市場傳出英特爾有意與友達合作Micro LED基板先進封裝，台積電亦傳出有意取得友達中科廠房，雙重題材帶動面板雙虎轉型先進封裝與Micro LED布局的想像空間。
  • 欣興 (3037) / 南電 (8046) / 景碩 (3189)：ABF載板產業進入新一輪超級循環，AI晶片與雲端服務供應商（CSP）積極預訂產能。外資預估AI伺服器將推升ABF載板整體面積需求成長3至4倍，ABF載板市場價值成長將於2025至2030年期間明顯加速。昨日三雄股價同步攻上漲停。
  • 漢測 (7856)：掛牌上櫃首日股價狂飆115.56%，最高達4,850元，躍居台股第11大高價股。公司主要業務涵蓋AI晶片所需高階探針卡、高速記憶體SLT、先進封裝設備及矽光子CPO測試。今年前8月營收年增125.94%，已超過去年全年，上半年EPS 21.5元。
  • 中美晶 (5483)：特斯拉執行長馬斯克看好太空太陽能產業，帶動中美晶股價強攻200元。公司已小量出貨太空應用PERC太陽能產品，並已做到第九級規範中的第七級，具市場領先地位。
  • 台達電 (2308)：董事長鄭平拜會印度總理莫迪，持續擴充在地產能並聚焦能源轉型、AI基礎設施及智慧製造。顯示公司積極搶攻AI與綠能新商機。
  • 中磊 (5388)：推出符合ITU-T國際標準的50G PON超高速光纖系列產品，旨在滿足快速增長的頻寬需求，加速推動網路向全光纖架構演進，並將於SCTE TechExpo26展出。
  • 東擎 (7710)：預計10月下旬掛牌上市，受惠於遊戲串流客戶大單，上半年每股稅後純益已超越去年全年獲利總和。AI Box產品也已接獲國內外訂單，對明年營運維持樂觀看待。
  • 嘉晶 (3016)：矽光子相關鍺矽（Ge/Si）磊晶需求強勁，客戶需求能見度已延伸至2028年，預計明年產能擴增3.5至4倍仍供不應求。Q3起功率元件產品線已啟動價格調漲，營運展望正向。
  • 國統 (8936)：拿下屏東縣政府「新園工業用地及新園產業園區委託開發案」，金額達38.77億元。2026上半年營收年增20.06%，稅後純益年增15.92%。
  • 中台資源 (6923)：取得台南市政府環保局「二仁溪河道廢棄物清理第二期專案計畫」，總承攬金額逾10億元，預計Q4啟動施作。2026上半年營收年增17%，稅後純益年增74%。
  • 中華汽車 (2204)：日本進口MITSUBISHI旗艦休旅車OUTLANDER正式上市，預計年底前銷量可達600輛，加上國產輕商車熱銷，預估Q4營運可望攀至今年單季新高。轉投資綠捷的四足機器人預計明年上半年量產。

⚠️今日重大個股利空

  • 緯創 (3231)：儘管台股創高，昨日緯創股價開高走低，終場下跌3.22%，外資對其大幅賣超3萬549張。分析師認為AI剛起步時為代工股最輝煌階段，目前最強勁的主升段可能已經過去，短線股價不易突破200元天險。
  • 南亞科 (2408) / 華邦電 (2344) / 旺宏 (2337)：記憶體族群昨日盤中由紅翻黑，南亞科下跌3.68%，華邦電下跌1.72%，旺宏下跌1.67%。分析師認為主要因高檔遇到反壓及買盤不足，但基本面並未轉差，仍有市場關切。投信大賣華邦電1萬5449張。
  • 兆豐金 (2886)：中華信評確認金控評等，但展望維持「負向」，主因核心子公司兆豐銀行法金業務市占率與營收下滑，營運狀況可能持續轉弱，恐對集團信用結構造成壓力。
  • 南僑 (1702)：總裁李勘文指出，受中聯油脂問題油事件影響，包括客戶退貨及相關損失將在第三季提列，將侵蝕獲利，H1稅後純益年減65.12%，對供應商福壽（1219）提出求償。

💡操盤手筆記

  • 市場氛圍：儘管台股昨日盤中衝上歷史新高48,601點後出現逾800點的劇烈震盪，尾盤漲幅收斂，但終場仍收在歷史新高47,800點。費半指數和台積電ADR的強勁表現，以及台指期夜盤的紅盤，預示今日台股在AI與半導體主導下，仍有機會維持偏多格局。然而，昨日大盤雖紅，逾千檔個股卻收黑，顯示資金輪動快速，分化行情明顯。
  • 資金流向：外資昨日再度大買447.26億元，連續第四日買超，並重金押注面板族群（友達兩天狂掃48萬張）及部分主動式ETF。聯電（2303）也獲外資與投信青睞。這顯示外資持續看好台灣科技供應鏈，並積極佈局。
  • 族群趨勢：
    • AI與半導體：AI依然是台股主旋律，從GPU需求擴散至ASIC、先進封裝、高階PCB/ABF載板、HBM、矽光子、散熱模組及測試設備等族群。聯發科、創意、信驊等高價股續創歷史新高，ABF載板三雄（欣興、南電、景碩）也同步漲停，顯示市場持續押注AI長期成長趨勢。新掛牌的漢測（7856）在矽光子與先進封裝領域的強勢表現也值得關注。
    • 面板：友達、群創受惠於先進封裝題材與外資買盤，表現強勁。
    • 記憶體與傳統AI：昨日南亞科、華邦電等記憶體股以及緯創等「老AI」代工股表現相對疲弱，顯示資金有從漲多族群流出，轉向新題材或具基本面支撐的個股。
    • 金融與房市：金管會將於今日正式上線「台股儀表板」，提升市場透明度，並強化違約交割控管，同時開放銀行試辦「存款代幣」業務，促進金融創新。央行鬆綁購地貸款限制，但8月房貸量因民俗月減少，房市仍呈中性看待。
    • 中小型股：台新臺灣中小主動式ETF（00416A）的推出，以及歷史數據顯示美國期中選舉後中小型股表現優於大型股，可能吸引資金關注具有基本面和成長潛力的中小股本企業。
    • 其他產業：台達電在印度拓展AI與綠能基礎建設，康舒聚焦歐洲快充市場，中鋼在再生鋼材和汽車產業佈局，國統在水資源工程，中台資源在環保工程，均有各自的利多與成長動能。
  • 風險提醒：中秋節連假前夕，市場可能出現獲利了結賣壓。同時，金管會針對違約交割祭出更嚴格的預收款券制度，可能對當沖及高槓桿交易者產生影響。川習會結果和美伊衝突後續發展也可能引發市場情緒波動。操作上建議保持靈活，逢低佈局具備明確基本面與成長趨勢的AI相關個股，並留意資金輪動節奏。
